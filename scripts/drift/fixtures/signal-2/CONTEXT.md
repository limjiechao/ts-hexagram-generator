# Demo glossary

**Changed Line**:
A line whose value turns into its opposite.
_Avoid_: `changing line`, `moving line`, shifting.

**Changed Line Pair**:
_Avoid_: `changing line` (as a noun), `stalk pile`, heap.

**Query**:
_Avoid_: `query text`, lookup,
`search term`, filter.

**Figure Name**:
_Avoid_: `gua` (in English text), `DRM`, `undo`, `trash`.

Prose may name `split point` outside any list.

_Avoid_: `saved at`, timestamp (for a file, or a reading).
